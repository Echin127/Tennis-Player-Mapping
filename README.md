# Tennis-Mapping
First set of files creates maps based on distribution of tennis players.
Web link: https://echin127.github.io/Tennis-Player-Mapping/

Data from Jeff Sackmann's incredible player databases, adapted for mapmaking use.

Second set of files is an interactive map plotting out the locations of the 2025 Professional men's tournaments.
Data from ITF and ATP websites. Geocdoded using geoapify.
